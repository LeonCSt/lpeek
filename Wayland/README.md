## **Lpeek** Manual install instructions


Copy or clone all the following files to one directory:-

Makefile

wpeek010.h

wpeek011.cpp

wpeek012.cpp

xdg-shell-protocol.cpp

xdg-shell-client-protocol.h

lpeek.conf

lpeek_example.bin

FreeMono.otf


## Then run:-
 
sudo make install


## To uninstall, run:-

sudo make clean

sudo make uninstall
